# Replica M3b: Collect Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Prerequisite:** main at `0f60df5` or later (M3a + Setup guide shipped; migrations through 0051 applied on dev).

**Goal:** A lead technician on site creates the job's invoice from captured materials, adds pricebook lines, has the customer sign in an approval sheet that finalizes the invoice, records a cash/check payment, and the invoice reads paid — with every money POST idempotent under retries, and no card surface anywhere while the provider is the mock.

**Architecture:** New pure-SQL writers in `src/lib/admin/invoice-field-writes.ts` (one `db.batch` each, lock order request → invoice → payment, xmin gates, enum casts, tenant params), an idempotency helper in `src/lib/http/idempotency.ts` (claim / replay / 422 / 2-minute takeover with `attempt_id` ownership; only 2xx and deterministic 4xx stored), tech routes under `src/app/api/tech/jobs/[id]/invoice*`, a client store-less S40 page with a pure key reducer, the invoice signature snapshot at finalize, server-derived ids for office money forms, the mock gate at the routes, and migrations 0052 (DDL + enum) / 0053 (backfill + template seed).

**Tech Stack:** Next.js 16 App Router (`params` is a Promise; read `node_modules/next/dist/docs/` before touching routes/pages), Drizzle 0.45 on Neon neon-http (`db.batch()` = one transaction; `db.execute(sql…)` returns `.rows`; `db.transaction()` throws), zod 4, `uuid@14` (`v5`), vitest pure tests (mocked `db`; SQL rendered with `new PgDialect().sqlToQuery`), base shadcn primitives in the tech app (`src/components/ui/*`), admin primitives in `src/components/admin/ui/*`.

**Spec:** `docs/superpowers/specs/2026-11-04-replica-m3b-collect.md` (v4 FINAL) — §3 data model, §4 idempotency, §5 writers, §6 tech API, §7 UI, §8 admin/portal, §9 erase, §10 tests, §12 rulings.
